# Phase 1 traceability

This file maps every proposed Requirement and Scenario to a future permanent test
and its evidence obligation. All named tests are **planned and not implemented or
run in this specification-only phase**. Current defect evidence refers to
`REPRODUCTION.md`; it proves current-head behavior, not remediation.

Evidence labels:

- `R006`: six mutable-source boundaries, all reproduced.
- `R007`: eight injectable mutation boundaries plus two current absent boundaries,
  uncertain remove effects, false restoration, mixed state, and rollback failure.
- `R008`: startup/repair receipt and content-drift matrix.
- `R009`: fresh/repair ignored bytecode matrix and Phase 0 uninstall change.
- `R010`: active/inactive/root/venv/package/special/concurrent unknown deletion.
- `W-NOT-RUN`: `NOT RUN — native Windows host unavailable`.
