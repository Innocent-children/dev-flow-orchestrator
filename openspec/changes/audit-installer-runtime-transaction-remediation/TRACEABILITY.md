# Phase 1 traceability

This file maps every Requirement and Scenario in this change to permanent tests that
currently exist in the repository and to their evidence obligations. Selector presence
is not itself an execution claim. This remediation session ran the focused R009, R010,
R006, R008, and R007 groups in that order; the combined installer, uninstaller,
managed-runtime, MCP-runtime, and installed-journey modules (122 tests); PowerShell
host-neutral and static checks (15 tests); and full discovery (462 tests, 22
native/platform skips).
Current-head defect evidence remains in `REPRODUCTION.md` and is not remediation
evidence. Native Windows lifecycle execution remains `W-NOT-RUN`.

Evidence labels:

- `R006`: mutable-source drift reproduced at six lifecycle boundaries.
- `R007`: false rollback, uncertain Codex effects, mixed state, and rollback failure.
- `R008`: startup/repair receipt and installed-content drift matrix.
- `R009`: fresh/repair ignored bytecode and Phase 0 source-retention behavior.
- `R010`: recursive loss across runtime/root/release/package/special/concurrent paths.
- `W-NOT-RUN`: `NOT RUN — native Windows host unavailable`.
