# install-versioned-release-artifact

Replace the persistent Git-checkout installer with one verified, version-addressed release artifact while preserving the bundled Codex Skill, STDIO MCP, managed runtime, task data, and existing Controller authority boundaries.

The change is complete when the final artifact has passed the bounded macOS and native Windows lifecycle gates defined in `design.md` and `tasks.md`. It does not create a general package manager, signing system, automatic updater, or arbitrary historical rollback service.
