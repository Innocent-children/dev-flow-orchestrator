# Frozen lite legacy workflow

## intake
Use the historical single-repository preflight protocol and preserve all dirt.

## preflighted
Bind the exact historical `lite` approval before implementation. Schema-v1
keeps legacy confirmation UX; schema-v2 keeps preview and intent binding.

## implementing
Edit only the declared low-risk paths. Reopen preflight when evidence changes.
The historical automatic verification edge remains schema-dependent, and an
unsafe live scope persists the historical `lite-risk` blocker.

## verifying
Record current passing tests. Rework implementation or reopen preflight through
the declared edges. Completion remains explicit and irreversible.

## blocked
Resume only to the recorded origin. A `lite-risk` blocker cannot resume and
requires explicit cancellation before a replacement full task.

## done
Read-only handoff. Never reopen.

## cancelled
Read-only history. Never reopen.
